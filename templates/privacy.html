Privacy

What this preview keeps.

The contact form checks that a name, email, and message are present. It then shows a thank-you note. It does not write the message to a database, and it does not email it on.

The live Vittorio shop still has the default WordPress privacy text, including a staging web address. That page should be rewritten on the live site before it is treated as policy. This preview does not copy that template.

Shop pages for an account, cart, and checkout are not part of this preview.
